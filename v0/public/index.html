How are repositories matched?

Score: tech-stack coverage (40), matching issue difficulty (30), latest push (15), and sampled maintainer review speed (15). We inspect README setup and testing instructions, 20 recent commits, 30 recently updated open issues and 3 recent pull requests. Missing review data earns no review points.

Easy = beginner issue label. Hard = advanced label or title. Other issues default to medium with low confidence. README complexity is a separate clue, not proof of task difficulty. Setup instructions cannot verify that code runs. Results are a bounded sample, not every matching GitHub repository; each search analyzes up to 6 candidates. Data is cached for 5 minutes.
